# 推送到 GitHub — 操作说明

本地仓库已准备好：分支 `main`、remote 已指向
`https://github.com/474738514h-stack/3d-asset-match-agent.git`，提交历史为有意义的中文 commit message。

自动推送失败的原因是 GitHub 连接器（App）没有这个新仓库的写权限（403），
需要从 GitHub 侧给一个带 `repo` 写权限的身份。下面两条路径任选其一。

---

## 路径 A：用 Personal Access Token 推送（推荐，最快）

### 1. 生成 Token
打开：https://github.com/settings/tokens
- 点 **Generate new token (classic)**
- Note 随便填，如 `match3d-push`
- Expiration 选 90 days 或 No expiration
- 勾选权限：**repo**（整个分组，含 repo:status / repo_deployment / public_repo）
- 点 Generate token，**复制那串 ghp_ 开头的字符串**

### 2. 推送
在终端执行（把 `YOUR_TOKEN` 换成刚才复制的字符串）：

```bash
cd /Users/hxm/WorkBuddy/2026-11-17-23-28-46/asset-matcher
git push -u https://474738514h-stack:YOUR_TOKEN@github.com/474738514h-stack/3d-asset-match-agent.git main
```

看到 `Branch 'main' set up to track ...` 和一串 `Writing objects` 即成功。
刷新 https://github.com/474738514h-stack/3d-asset-match-agent 就能看到 README 和全部文件。

> 安全提示：Token 等同于密码，别截图、别发给别人。推送成功后如需撤销，去上面的 tokens 页面删除即可。

---

## 路径 B：给 GitHub 连接器授权此仓库后，让我重试

如果你更想继续用连接器：
1. 打开 https://github.com/settings/installations
2. 找到 WorkBuddy 的 GitHub App 安装 → Configure
3. 在仓库列表里勾选 `3d-asset-match-agent` → Save
4. 回来告诉我，我重新执行推送。
